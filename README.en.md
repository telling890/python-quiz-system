A desktop quiz app for the lab exercises of *Python Programming* (chapters 3–5). 139 questions,
338 test cases, instant judging, wrong-answer book, mock exams with weighted paper generation.
Download the portable zip from
[Releases](https://github.com/telling890/python-quiz-system/releases/latest) and run
`Python刷题系统.exe` — no Python required.
